# Factory Growth Lab

We build English websites and run Google SEO + AI-search (GEO) programs for Chinese export factories.

Website: https://www.factorygrowthlab.com

## Free tools and resources

- [B2B Schema Markup Generator for Manufacturers](https://www.factorygrowthlab.com/en/schema-generator) — Generate paste-ready Organization and Product JSON-LD in your browser. No sign-up.
- [Factory Website AI and GEO Readability Checker](https://www.factorygrowthlab.com/en) — An 8-point rules-based check on the homepage: enter a public URL to check crawl access, server HTML, entity structure, buyer evidence, and inquiry paths. No sign-up. This is not an AI recommendation score.
- [25-Point Export Website Self-Audit Checklist](https://www.factorygrowthlab.com/en/free-checklist) — 25 checks in 5 groups, from crawling and indexing to the inquiry path.
- [B2B Manufacturing Export Glossary](https://www.factorygrowthlab.com/en/glossary) — 16 export terms (MOQ, OEM/ODM, COA, Incoterms, inquiry grading) with one-line definitions and what each means in procurement.
